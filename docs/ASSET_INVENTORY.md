## Phase 01C usage

No assets were added, replaced or removed. All 83 existing manifest references / 48 original hashes pass validation. Place Details uses the seven original `details/` destination/gallery/map/experience images; My Discoveries uses its original six destination photographs, explorer-avatar, combined achievement artwork and duration/cost icons. Profile reuses the explorer illustration; account screens reuse branding without adding stock imagery.

`public/data/demo-destinations.json` associates each record with its appropriate per-screen image. Ajloun intentionally keeps the differing Explore/Result, Details and Discoveries photographs from Figma. Iraq Al-Amir and Umm Qais were added from the original Discoveries frame, with no fabricated travel time or coordinates. Other destinations have no full source Details gallery/map/description; those gaps remain visible. Asset validation now checks all nested demo-data references against the existing manifest and rejects temporary Figma URLs in public JSON as well as source code.

Required original raster assets are available. Standalone component/progress exports and fresh Figma inspection remain limited by the MCP quota. Missing runtime photographs show a labeled fallback instead of an unrelated image. See the [Phase 01C report asset table](./PHASE_01C_REPORT.md#assets-used).
