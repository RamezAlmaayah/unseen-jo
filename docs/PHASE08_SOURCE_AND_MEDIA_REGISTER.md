- [Um er-Rasas municipality](https://um-arrassas.gov.jo/ar/about-us/) corrects the dossier governorate to Amman, Al-Jizah district. Madaba proximity does not make it Madaba governorate.
- Pella JTB directions target resolved near Amman and was rejected. Wikidata approximate archaeological location retained with explicit qualification; no exact gate asserted. [Cross-checks](evidence/phase08/geography-links.json).
